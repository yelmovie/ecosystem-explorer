# 생명의 그물 지도

2026-10-28 시각 고도화: 참고 프로젝트의 큰 2D 탐구 무대·떠 있는 메뉴·따뜻한 패널 구성을 적용했어. 학습 삽화 18개를 생성·최적화해 관찰·분류·실험·먹이그물·환경 전후 비교·복원 대책·엔딩에 연결했어. 지도만 2.5D 픽셀아트로 유지해. 자세한 근거와 검증은 [시각 고도화 기록](docs/VISUAL-UPGRADE-20261028.md)에 있어.

초등 4학년 「생물과 환경」 웹게임이야. 메인 → 사선 조감 픽셀 탐험 지도 → 5장 × 2개 활동 → 최종 설계·시험·수정 → 엔딩·인증서로 이어져. 2026-10-28에 전체 활동의 반복 클릭을 줄였어. 마지막 학습 행동에서 자동 기록되고, 다음 탐험으로 바로 이어져. 15초 개념 영상(모아의 탐사 노트, 10편)은 완료 안내에서 원할 때 볼 수 있어.

## 실행

Node.js 20 이상이 필요해. 외부 패키지 설치는 없어.

```sh
cd '/Volumes/T7 Shield/iscreammedia_sc34/14 environments'
# 연결된 외장 SSD임을 확인한 뒤 캐시와 임시파일 경로도 지정해.
mkdir -p artifacts/runtime/tmp artifacts/runtime/cache artifacts/runtime/npm-cache
export TMPDIR="$PWD/artifacts/runtime/tmp"
export TMP="$TMPDIR" TEMP="$TMPDIR"
export XDG_CACHE_HOME="$PWD/artifacts/runtime/cache"
export npm_config_cache="$PWD/artifacts/runtime/npm-cache"
npm run build
npm run preview
```

브라우저에서 http://127.0.0.1:4184 를 열어. 다른 프로그램이 포트를 쓰고 있으면 `PORT=4185 npm run preview`로 실행해.

- 소스 개발 서버: `npm run dev`
- JavaScript 구문 검사: `npm run check`
- 저장·해금·생태 모형 검사: `npm test`
- 개념영상 다시 만들기(HyperFrames): `SHARP_MODULE=<sharp 경로> node films/build.mjs` → `TMPDIR=<외장 SSD 임시 폴더> node films/render.mjs [p01 …]`, 자막은 `node scripts/make-vtt.mjs`. 시간표는 `src/learning.js`의 `conceptClock` 하나로 맞춰. 검토 기록은 [films/REVIEW.md](films/REVIEW.md).
- 화면 그림 WebP 사본·공유 썸네일 다시 만들기: `SHARP_MODULE=<sharp 경로> node scripts/make-web-assets.cjs`
- 정적 배포 파일: `dist/` (웹 서버에서 실행. `index.html`을 파일로 직접 열면 ES module이 작동하지 않을 수 있어.)

## 조작

- 지도: 땅을 누르거나 방향키 / WASD로 사람 탐험가를 움직여. 다람쥐 도토가 따라와. 장소 버튼으로 바로 활동을 선택할 수도 있어.
- 분류·역할: 선택된 카드의 상자·역할을 눌러. 배치 뒤 다음 카드가 자동 선택돼. 카드를 직접 고르거나 끌어 놓아 수정할 수도 있어.
- 원인 추적: 카드를 한 번 누르면 해당 칸에 놓여. 세 선택이 맞으면 다음 현장으로 이어져.
- 역할 실험: 예상을 고르면 시간 변화가 자동 진행돼. 원래 역할을 복원하고 결과를 설명해.
- 관계 연결: 먹히는 생물 → 먹는 생물로 직접 끌거나 눌러. 이어갈 출발점은 자동 선택돼. 선택된 생물을 다시 누르면 선택을 해제하고, 마지막 선은 되돌릴 수 있어.
- 시간 비교: 사진을 쓸거나 슬라이더·전후 보기 버튼을 사용해. 두 대책의 네 장면을 보면 같은 화면에서 발견을 설명할 수 있어.
- 개념·안내에서 핵심 개념, 그림과 생각 나누기, 조작 안내를 볼 수 있어. 현재 단계의 다음 버튼은 테두리로 표시돼.
- 힌트는 활동 오른쪽 도토를 눌러 단계별로 열 수 있어. 개념 영상은 완료 후 다시 볼 수 있어.
- 복원 작전: 계획을 바꿔 실행하고 지난 작전의 결과와 비교해.
- 최종 미션: 앞에서 완성한 먹이그물을 가져오거나 직접 설계할 수 있어. 환경 요소와 보전 대책을 갖춰 시험하고, 메뚜기 없이 시험을 거쳐 대체 먹이 경로를 확인해야 완료돼.
- 설정 → **모든 장·활동 한 번에 열기**: 교사용 시연. 완료·증거를 자동으로 만들지 않아.
- 홈·이전·소리·설정은 공통 상단에 있어. 설정에서 움직임 줄이기와 진행 초기화를 제공해. 움직임을 줄이면 개념 영상 자동 재생도 꺼져. 초기화는 확인 단계가 있어.
- 엔딩에서 생활 속 실천 약속을 고르면 기록에 저장돼. 선택한 약속은 인증서에도 표시돼. 실제 실천은 수업 뒤에 이어 가.
- 인증서: 이름 입력 없이 인쇄 / 브라우저 PDF 저장. 인쇄 환경별 실제 출력은 추가 확인이 필요해.
- 생태 설계 미션은 생물 배치 → 먹이 연결 → 환경 변화 관찰의 3단계야. 선택한 도구 안내와 한 번 되돌리기를 제공해.
- 태블릿 가로는 한 화면 무대를 사용해. 폭 1000px 미만 또는 높이 562px 미만에서는 세로 스크롤 배치로 전환해 실제 글자와 터치 영역 크기를 확보해.

## 저장

`life-web-map:mvp:v1` 키로 활동 중간 상태·완료·설계·소리 설정을 이 브라우저에 저장해. 계정·이름·학번 수집과 서버 전송은 없어. 주소(origin), 브라우저, 기기가 달라지면 기록이 공유되지 않아. 브라우저의 사이트 데이터를 지우면 진행도 지워져. 오프라인 새로고침은 지원 범위 밖이야.

추가 설계 미션은 별도 키 `science-play-14-v1`에 저장해. 설정의 백업·초기화·복구 대상은 10개 탐험 활동 기록이야. 두 저장소 모두 손상된 원문과 다른 창에서 변경한 기록을 보호하고 저장 실패를 화면에 알려 줘.

## 범위와 남은 검토

복원 예산은 6포인트야. 지도는 2.5D 픽셀아트이고 장소 안은 2D야. 수달 모아는 연구원 안내자, 다람쥐 도토는 탐험 동행·힌트 친구야. 제공된 AI 배경·로고·캐릭터를 재사용하고 지도·도토·개념 도형 모션을 코드로 만들었어. 현재 개념 영상 10편은 HyperFrames의 「모아의 탐사 노트」 MP4야. 엔딩은 2D 복원 삽화와 CSS 연출을 사용해.

영상 재생 시에만 해당 파일을 불러와. 각 영상은 약 15초이고 10편 합계 약 4.2MiB야. 큰 한국어 문장·도형 모션·효과음으로 구성돼. 별도 화면 안내 음성은 모아·도토 대사 27개를 연결했어. 제작·검증 세부 내용은 [영상 검토](films/REVIEW.md), [음성 통합 기록](docs/reviews/FINAL-VOICES-20261110.md), [효과음 출처](assets/audio/SOURCES.md)에 있어.

현재 영상 재제작 명령은 위 실행 절의 `films/build.mjs`와 `films/render.mjs`를 사용해. 원본 장면과 자막의 시간 기준은 `src/learning.js`의 `conceptClock`에 맞춰.

생태 모형은 관계와 환경 변화에 대한 판단 연습에 사용해. 7개 브라우저 뷰포트와 마우스·터치 이벤트를 검증했어. 교육과정 원문 대조 기록이 있으며 교사 난이도 검수, 학교 실제 기기의 가독성·펜 감도·네트워크 속도, 원본 에셋의 배포 권리 확인이 남아 있어.

운영 주소는 [생명의 그물 지도](https://ecosystem-explorer.yelsam.workers.dev/)이고 GitHub 저장소는 `yelmovie/ecosystem-explorer`야. `dist/`를 기존 Cloudflare Workers 정적 에셋으로 배포해. 배포 직전 버전과 운영 검증 결과는 [교육·최종 배포 검토](docs/reviews/EDUCATION-20261112.md), 항목별 평가는 [점수표](docs/reviews/SCORE-20261111.md)에 기록해.

기존 검토 자료: [시나리오](docs/SCENARIO_REVIEW.md), [에셋](docs/ASSET_REVIEW.md), [이전 인계](HANDOFF.md).
