# 생명의 그물 지도

2026-10-28 시각 고도화: 참고 프로젝트의 큰 2D 탐구 무대·떠 있는 메뉴·따뜻한 패널 구성을 적용했어. 학습 삽화 18개를 생성·최적화해 관찰·분류·실험·먹이그물·환경 전후 비교·복원 대책·엔딩에 연결했어. 지도만 2.5D 픽셀아트로 유지해. 자세한 근거와 검증은 [시각 고도화 기록](docs/VISUAL-UPGRADE-20261028.md)에 있어.

초등 4학년 「생물과 환경」 웹게임이야. 메인 → 사선 조감 픽셀 탐험 지도 → 5장 × 2개 활동 → 최종 설계·시험·수정 → 엔딩·인증서로 이어져. 2026-10-28에 전체 활동의 반복 클릭을 줄였어. 마지막 학습 행동에서 자동 기록되고, 다음 탐험으로 바로 이어져. 12초 개념 영상은 완료 안내에서 원할 때 볼 수 있어.

## 실행

Node.js 20 이상이 필요해. 외부 패키지 설치는 없어.

```powershell
cd 'F:\iscreammedia_sc34\14 environments'
npm run build
npm run preview
```

브라우저에서 http://127.0.0.1:4184 를 열어. 이미 실행 중이면 그 주소를 그대로 사용하면 돼. 다른 프로그램이 포트를 쓰고 있으면 `$env:PORT='4185'`를 지정하고 다시 실행해.

- 소스 개발 서버: `npm run dev`
- JavaScript 구문 검사: `npm run check`
- 저장·해금·생태 모형 검사: `npm test`
- 정적 배포 파일: `dist/` (웹 서버에서 실행. `index.html`을 파일로 직접 열면 ES module이 작동하지 않을 수 있어.)

## 조작

- 지도: 땅을 누르거나 방향키 / WASD로 사람 탐험가를 움직여. 다람쥐 도토가 따라와. 장소 버튼으로 바로 활동을 선택할 수도 있어.
- 분류·역할: 선택된 카드의 상자·역할을 눌러. 배치 뒤 다음 카드가 자동 선택돼. 카드를 직접 고르거나 끌어 놓아 수정할 수도 있어.
- 원인 추적: 카드를 한 번 누르면 해당 칸에 놓여. 세 선택이 맞으면 다음 현장으로 이어져.
- 역할 실험: 예상을 고르면 시간 변화가 자동 진행돼. 원래 역할을 복원하고 결과를 설명해.
- 관계 연결: 먹히는 생물 → 먹는 생물로 직접 끌거나 눌러. 이어갈 출발점은 자동 선택돼. 선택된 생물을 다시 누르면 선택을 해제하고, 마지막 선은 되돌릴 수 있어.
- 시간 비교: 사진을 쓸거나 슬라이더·전후 보기 버튼을 사용해. 두 대책의 네 장면을 보면 같은 화면에서 발견을 설명할 수 있어.
- 힌트: 활동 오른쪽의 도토를 누르면 단계별 힌트가 열려. 개념 영상은 완료 후 다시 볼 수 있어.
- 복원 작전: 계획을 바꿔 실행하고 지난 작전의 결과와 비교해.
- 최종 미션: 앞에서 완성한 먹이그물을 가져오거나 직접 설계할 수 있어. 환경 요소와 보전 대책을 갖춰 가동하고, 메뚜기 부재 시험을 거쳐 대체 먹이 경로를 확인해야 완료돼.
- 설정 → **모든 장·활동 한 번에 열기**: 교사용 시연. 완료·증거를 자동으로 만들지 않아.
- 홈·이전·소리·설정은 공통 상단에 있어. 설정에서 움직임 줄이기와 진행 초기화를 제공해. 움직임을 줄이면 개념 영상 자동 재생도 꺼져. 초기화는 확인 단계가 있어.
- 인증서: 이름 입력 없이 인쇄 / 브라우저 PDF 저장. 인쇄 환경별 실제 출력은 추가 확인이 필요해.

## 저장

`life-web-map:mvp:v1` 키로 활동 중간 상태·완료·설계·소리 설정을 이 브라우저에 저장해. 계정·이름·학번 수집과 서버 전송은 없어. 주소(origin), 브라우저, 기기가 달라지면 기록이 공유되지 않아. 브라우저의 사이트 데이터를 지우면 진행도 지워져. 오프라인 새로고침은 지원 범위 밖이야.

## 범위와 남은 검토

복원 예산은 6포인트야. 지도만 2.5D 픽셀아트이고 장소 안은 2D야. 수달 모아는 연구원 안내자, 다람쥐 도토는 탐험 동행·힌트 친구야. 기존 AI 배경·로고·캐릭터 4개는 그대로 재사용했어. 지도·도토·개념 도형 모션은 코드로 만들었어. 개념 영상 10편은 Pillow와 FFmpeg로 제작한 실제 MP4이며, 엔딩은 생성한 2D 복원 삽화와 CSS 연출을 함께 사용해.

영상 재생 시에만 해당 파일을 불러와. 10편 합계 약 0.96 MiB이고 나레이션 없이 큰 한국어 문장과 도형 모션으로 구성돼. 효과음 7종은 약 19 KiB야. 제작·검증 세부 내용은 [개선 기록](docs/EXPERIENCE-UPGRADE-20261022.md), [효과음 출처](assets/audio/SOURCES.md)에 있어.

영상 재제작은 Python의 Pillow와 FFmpeg가 설치된 환경에서 `python scripts/make-concepts.py`로 실행해. FFmpeg 위치가 다르면 `FFMPEG` 환경 변수에 실행 파일 경로를 지정해. 게임 실행에는 Python이나 FFmpeg가 필요하지 않아.

생태 모형은 실제 개체수나 회복 일수 예측이 아니야. 7개 브라우저 뷰포트와 마우스·터치 이벤트를 검증했어. 학교 실제 기기의 가독성·펜 감도·네트워크 속도, 한국 교육과정 원문과 난이도, 원본 에셋의 배포 권리는 출시 전에 확인해야 해. 외부 배포·온라인 서비스 연결은 하지 않았어. GitHub 저장소는 운영시트 14번의 `yelmovie/ecosystem-explorer`를 사용해.
