# 스테이지 흐름 개선 · 2026-10-28

전체 10개 활동의 반복 조작과 불필요한 확인을 줄였어. 기존 완료 조건·생태 모형·저장 키·에셋을 유지했고, 새 이미지나 음원을 만들지 않았어. 원본은 `artifacts/before-flow-polish/`에 보관했어.

## 바뀐 경험

| 활동 | 개선 |
| --- | --- |
| 공통 | 유효한 마지막 학습 행동에서 자동 기록. 화면 안에 완료 안내와 다음 탐험 버튼. 개념 영상은 선택해서 재생. 이미 완료한 활동을 다시 조작해도 중복 완료·성공음 없음. |
| P01 | 이미 찾은 설명은 고정. 정답 뒤 키보드 포커스는 다음 미발견 관찰 지점으로 이동. |
| P02·P03 | 처음 카드와 다음 미배치 카드 자동 선택. 학생은 분류 상자·역할을 직접 판단. 오답 수정과 드래그 유지. |
| P04 | 예상 선택과 동시에 실험 시작. 두 시간 변화 자동 진행, 결과 바로 보기 제공. 역할 복원과 결과 설명은 필수. 화면 이탈·숨김·모달에서 타이머 정리, 복귀 시 재개. |
| P05 | 성공한 연결에서 다음 출발점 자동 선택. 가지 연결을 연속으로 만들고 다른 출발점으로 전환 가능. 마지막 선 되돌리기 유지. |
| P06 | 두 제거 시험 뒤 같은 화면에 설명 질문. 복원 뒤에도 시험 기록을 인정하고 보고서에 실제 시험 목록 표시. |
| P07 | 카드 한 번 선택으로 해당 슬롯 배치. 올바른 세 카드를 갖추면 다음 사건으로 진행. 틀린 인과 고리는 수정 가능. |
| P08 | 두 대책·네 장면 관찰 뒤 같은 화면에 질문. 스와이프·슬라이더와 전후 보기 버튼 모두 지원. |
| P09 | 실행한 작전의 결과 화면을 새로고침·재진입에서 복원. 선택 이유에서 자동 기록. |
| P10 | 완료한 P05의 유효한 먹이그물만 선택적으로 가져오기. 환경·대책·시험은 직접 수행. 메뚜기 부재 버튼 한 번으로 실제 시험까지 실행. 성공한 시험의 중복 실행 버튼 정리. 엔딩 바로 표시. |

## 파일

- `src/app.js`: 입력·진행·자동 기록·실험 타이머·포커스·보고서.
- `src/progress.js`: 자동 기록 조건, 다음 카드·연결 선택, 검증된 먹이그물 복사. 가져오기는 기존 환경·대책을 보존하고 이전 시험 결과를 무효화해.
- `src/experiences.js`, `src/learning.js`: 단계별 화면·힌트·다음 행동 안내.
- `src/experience.css`: 기존 크림·숲색 토큰으로 완료 안내와 비교 질문 배치. 작은 화면은 세로로 흐르게 하고 가로 넘침 방지.
- `tests/progress.test.mjs`, `scripts/verify-experience.cjs`: 완료 조건·오답·기록 복사와 실제 브라우저 회귀검사.
- `package.json`, `README.md`: 검사 대상과 조작 안내 갱신.

## 검증

- `npm run check`, `npm test` (18개), `npm run build` 통과.
- 빌드된 `dist`를 Chrome에서 실행해 관리자 해금 없이 P01부터 P10 인증서까지 통과.
- 오답 수정, 중복 관계·기록 방지, 기본 가동 성공 → 메뚜기 부재 실패 → 설계 수정 → 성공, 인증서 새로고침 확인.
- P04 이탈·복귀·시간 건너뛰기·새로고침, P06 복원 후 완료, P09 결과 복원, P10 가져오기 뒤 필수 환경 미충족 차단 확인.
- 선택적 영상 재생·10개 미디어 범위 요청·영상 실패 시 글 안내·음소거·움직임 줄이기 확인.
- 1366×768, 1280×720, 1024×768에서 10개 활동의 가로 넘침과 주요 44px 터치 영역 검사. 1024×768 터치 입력과 카드 자동 선택 확인.
- 브라우저 예외와 HTTP 오류 0건. 결과: `artifacts/experience-check/result.json`, 화면 캡처: 같은 폴더.
- 작성자와 별도 에이전트가 진행·저장·입력 경계를 검토했고, 연결 출발점 전환·관찰 포커스·복원된 비교 보고서·슬라이더 상태 표시 지적을 반영했어.

실제 태블릿·전자칠판과 학교 네트워크 검증은 하지 않았어. 일부 작은 화면에서 세로 스크롤을 사용해. 로컬 개선·검증이며 외부 배포는 포함하지 않아.
