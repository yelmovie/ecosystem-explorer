# 14 게임 미션 1차

기존 탐구 내용·진도·에셋을 보존하고 개념을 직접 사용하는 3단계 설계 미션을 추가한다. 기존 학습 전체를 대체했다고 보지 않는다. 새 미션은 별도 로컬 키에 저장하고 기존 완료 기록을 변경하지 않는다.

조작: 도구 선택→공간 배치(15는 관 회전·모양·밸브)→환경/장치 시험→조건별 피드백→되돌리기/수정→다음 조건.

학습 증거: 배치·연결 상태와 시험 결과. 점수나 조작 속도로 과학 이해를 단정하지 않는다. 화면의 모델 주석을 유지한다.

검증 완료: 순수 모델 정답·실패·대안, 3미션 자연 조작, 재진입/저장/닫기/반복 클릭, 화면 크기 및 회귀. 1280×800, 1024×768, 844×390, 390×844 터치 에뮬레이션에서 3미션 성공·저장·재진입과 수평 넘침/44px 미만 버튼 검증. 실물 태블릿은 미시험.
