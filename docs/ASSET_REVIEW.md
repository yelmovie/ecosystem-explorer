# 에셋 검토 및 폴더 안내

원본 PNG 50개와 ZIP 1개를 용도별로 이동했어. 파일명과 바이트 내용은 모두 유지했고 SHA-256으로 확인했어. ZIP을 안전한 프로젝트 하위 경로에 해제한 PNG 10개는 기존 sample_v2 이미지 10개와 각각 내용이 같아. 중복본은 삭제하지 않았어.

| 경로 | 내용 | 용도 |
|---|---|---|
| assets/backgrounds/originals | 생성 이미지 26~35, 10장 | 2D 자연 배경 후보 |
| assets/branding/originals | 36~38 타이틀 시안, 39 투명 로고 | 브랜딩 참고 및 로고 |
| assets/characters/originals | 40 투명 캐릭터 시트 | 모아 표정·포즈와 동물 참고 |
| references/ui-exploration | 01~15, 15장 | 여러 페이지를 한 장에 모은 초기 화면 시안 |
| references/ui-pages | 16~25, 10장 | 개별 화면 시안 |
| references/sample-pages-v2 | sample_v2_P01~P10, 10장 | 장별 시나리오 검토의 주 참고 |
| references/archives | 원본 ZIP 1개 | 보관용 |
| references/extracted/sample-pages-v2 | ZIP 해제본 10개 | 원본 압축 내용 확인용 |
| references/contact-sheets | 비교용 목록 이미지 5장 | 전체 그림을 빠르게 비교 |
| references/asset-inventory.json | 이미지 크기·모드·해시 및 중복 정보 | 에셋 목록 |
| references/file-moves.json | 원래 경로와 새 경로 | 이동 내역 |

현재 자료에 앱 소스, 실행 가능한 샘플 페이지, 3D 모델은 없었어. 샘플 페이지는 PNG 화면 이미지야.

## 재사용 판단

- 배경은 RGB 이미지이며 대체로 자연 풍경이 완성되어 있어. 활동 공간과 카드 영역을 배치할 때 복잡한 배경 위 글자 대비를 확인해야 해.
- 로고 39번과 캐릭터 시트 40번은 RGBA 이미지야. 투명 채널이 있으나 캐릭터가 분리된 개별 파일이나 걷기 스프라이트 시트는 아니야.
- 모아의 정면 계열 표정과 포즈를 참고할 수 있어. 지도 이동에 필요한 옆·뒤 방향과 걷기 프레임은 추가 제작 대상이야.
- 샘플 P04의 입체 모형은 실제 3D 모델이 아니라 한 장의 그림이야. 2D 레이어나 상태별 렌더로 구현할 수 있어.
- 현재 에셋에는 이번 요청의 2.5D 픽셀아트 이동 지도가 완성되어 있지 않아. 배경과 캐릭터의 최종 지도 스타일은 별도 제작이 필요해.

## 설계에 그대로 가져오지 않을 요소

- P04와 다른 페이지의 진행 단계 표기가 달라. 공통 진행 체계를 정해야 해.
- P09에는 증거 4/5와 90%가 함께 표시돼. 증거 비율과 전체 활동 진행률을 섞지 않아야 해.
- P09의 복원 예산은 6이고 개별 화면 시안 24번은 8이야. 확정 전 수치로 취급해.
- P05·P06 및 다른 먹이그물 시안은 생물 구성과 화살표가 서로 달라. 생물 종과 화살표 의미를 검토한 데이터가 필요해.
- 안내 캐릭터는 모아, 부엉이, 너구리가 섞여 있어. 공유 대화에서 부엉이 캐릭터 사용 금지가 확인됐으므로 해당 캐릭터는 재사용하지 않아. 수달 연구원 모아를 안내 NPC로 사용해.
- 이미지에 합성된 버튼·글자·진행률은 참고용이야. 실제 UI는 독립된 요소로 구현해야 작동·수정·접근성 대응이 가능해.

검토 방식: 모든 원본 이미지의 크기·형식·해시를 확인했고 목록 이미지로 시각 검토했어. P04, P06, P09와 캐릭터 시트는 원본 크기로 추가 확인했어. 작은 시안 콜라주의 모든 문구를 OCR로 추출하거나 학습 내용 전체를 검증한 것은 아니야.
