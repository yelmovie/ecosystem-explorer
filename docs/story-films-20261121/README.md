## 다시 합성하는 법

임시 장면이 Veo로 바뀌면:

1. `.tmp/story-video-20261121/clips/<장면>.mp4`만 바꾼다.
2. `python3 compose2.py intro|finale`을 실행한다(이 폴더의 `compose2.py`가 원본).
3. `build/*-app.mp4`·`*-poster.jpg`를 `assets/concepts/story-*.mp4·jpg`로 복사한다.

자막 큐는 `*-captions.json`, 모션그래픽은 `*-deco.ass`, 대사 시점은 `*-cues.json`에 있다.
