# 생명의 그물 지도 장별 시나리오 검토안

작성일: 2026-10-14. 상태: 대화용 초안. PRD/TRD 확정과 MVP 구현 전 검토 자료.

공유 대화 「14생물과 환경_4-2」의 공개 본문을 직접 읽은 뒤 폴더의 샘플과 대조해 수정했어. 원문은 references/shared-conversation/transcript.md에 저장했어. 첨부 문서의 다운로드 링크와 이미지 목록은 확보했지만, 로그인 필요한 원격 첨부 원본까지 모두 내려받아 검토한 것은 아니야.

이전 대화의 설계 흐름을 유지하되, 이번에 정한 '스테이지 선택만 2.5D 픽셀아트, 장소 내부는 2D'를 최신 화면 기준으로 적용해.

## 이번 요청에서 확정된 기준

- 메인 화면 다음에 자연 속 스테이지 선택 지도가 나와.
- 이 지도에서만 위에서 사선으로 내려다보는 2.5D 픽셀아트 RPG 표현을 사용하고 캐릭터가 걸어 다녀.
- 지도에서 장소로 들어가면 기존 게임 스타일의 2D 활동 화면으로 전환해. 현재 폴더의 2D 참고는 자연 일러스트 배경, 큰 카드와 버튼, 수달 안내 캐릭터야.
- 모든 화면 왼쪽 위에 홈과 이전 아이콘, 오른쪽 위에 소리와 설정 아이콘을 둬.
- 설정의 관리자 전체 해금은 한 번에 모든 장과 활동을 열어. 장별·섹션별 해금 메뉴로 나누지 않아.
- 먼저 장별 시나리오를 대화하고 그 결과를 PRD/TRD와 MVP로 이어가.
- 3D용 기본 이미지 목록과 프롬프트는 별도 문서에서 검토해.

## 공유 대화에서 추가 확인한 요구

- 대상은 4학년 2학기 「생물과 환경」이야. 5학년 자료는 기능과 학습 구조만 벤치마킹하고 고학년 개념을 그대로 가져오지 않아.
- 제목은 「생명의 그물 지도」, 학습 화면은 5개 스테이지 × 2화면 = 10개야. 이번 요청의 메인과 탐험 지도는 그 앞에 붙는 공통 화면으로 구분해.
- 전자칠판·태블릿 가로·웹앱에 맞춰 밝고 귀여운 자연 분위기와 뒷자리에서도 읽을 수 있는 큰 UI를 사용해. UI는 CSS로 구현할 예정이었어.
- 부엉이 캐릭터는 사용 금지야. 기존 샘플에 등장해도 신규 화면에 재사용하지 않아. 안내 NPC는 수달 생태연구원으로 정리되어 있었어.
- 반복적인 드래그 분류와 OX 중심 구성을 피하고 관찰·관계 표현·변인 조작·시간 비교·자원 배분·재실행이 각각 학습에 쓰이게 해.
- 후기 심화안의 흐름은 Quest → Evidence → World Change → Final Report → Final Mission → Final Movie → Certificate야. 증거 5종과 세계 변화 5단계, 탐구 스타일과 Bonus Quest도 심화안에 언급돼. 구체적인 MVP 포함 범위는 이후 대화에서 조정해.

## 자료에서 확인한 흐름

샘플 v2는 5개 미션을 각각 두 화면으로 다루고 있어. 아래는 그 흐름을 게임의 장으로 묶어 읽은 것이야. 샘플은 시각 참고이며, 그림 속 수치·화살표·문구를 그대로 정답 데이터로 쓰지는 않아.

| 장 | 샘플 | 상황과 플레이어 행동 | 장을 마칠 때 남는 이해 |
|---|---|---|---|
| 1장 이상 신호를 조사하자 | P01 현상 조사, P02 구성 요소 분석 | 숲과 물가에서 이상 신호가 있는 지점을 관찰하고, 발견한 대상을 생물 요소와 비생물 요소로 분류해. | 생태계는 생물과 주변 환경이 함께 이루고 있다는 것 |
| 2장 생물의 역할을 알아내자 | P03 양분 관계 분석, P04 역할 실험 | 먹이와 분해의 흔적으로 생산자·소비자·분해자를 구분하고, 역할 그룹 하나가 없을 때를 실험해. | 각 역할이 서로 연결되어 있고 빠졌을 때 다른 변화가 생긴다는 것 |
| 3장 먹이그물 연결을 복구하자 | P05 먹이그물 구성, P06 먹이그물 충격 실험 | 먹히는 생물에서 먹는 생물 방향으로 연결하고, 한 생물이 사라진 경우 먹이 경로를 비교해. | 생물 사이의 관계가 여러 갈래로 연결되며 변화가 다른 생물에도 영향을 준다는 것 |
| 4장 변화의 원인을 추적하자 | P07 영향 원인 추적, P08 시간 변화 분석 | 인간 활동·환경 변화·생물 영향을 증거로 연결하고, 시간에 따른 상태 변화를 관찰해. | 눈에 보이는 결과와 원인을 구분하고 근거를 들어 설명하는 것 |
| 5장 생태계를 복원하자 | P09 생태 복원 작전, P10 생명의 그물 지도 | 한정된 자원으로 복원 행동을 조합한 뒤, 생태계 요소와 먹이 관계를 직접 구성하고 가동·수정해. | 앞에서 모은 증거를 종합해 설계하고 결과에 따라 다시 고치는 것 |

## 화면 순서 제안

메인 → 자연 탐험 지도 → 선택한 장의 첫 활동 → 두 번째 활동 → 장의 조사 결과 → 자연 탐험 지도.

5장의 P10은 단순한 복원 결과 화면이 아니라 직접 조작하는 최종 미션이야. 누적 증거를 정리하는 Final Report, 종합 생태계 설계·가동, 성공 후 Final Movie와 인증서까지 하나의 마무리 흐름으로 이어져. 학습 10화면을 유지하려면 보고서·엔딩·인증서를 P10의 내부 단계로 묶는 방식부터 검토할 수 있어.

지도에는 다섯 장으로 들어가는 명확한 목적지를 배치해. 장소명과 배치는 아직 제안 단계야. 관찰 물가, 역할 실험 공간, 먹이 관계 관찰터, 환경 조사 구역, 복원 거점처럼 활동의 의미를 드러내는 이름이 적합해.

지도를 걷는 시간이 매번 길어지지 않도록 이동과 장소 선택을 함께 지원하는 방향을 권해. 캐릭터 이동 방식, 플레이어가 수달 모아인지 별도 탐험가인지는 대화에서 정하면 돼.

## 각 활동의 시나리오와 완료 조건 제안

### 1장

P01에서 모아가 이상 신호를 알려주면 플레이어가 관찰 지점을 눌러 단서를 찾아. 발견 개수만 채우기보다 관찰한 대상과 특징 하나를 연결하도록 구성해.

P02에서는 관찰 대상을 올가미로 묶고 분류 기준을 생각한 뒤 생물 요소·비생물 요소라는 용어를 제시하는 흐름이었어. 숲·하천·갯벌 등 다른 생태계에도 같은 기준을 적용하는 비교가 포함돼. 단순히 두 칸에 카드만 넣는 활동으로 축소하지 않아. 버섯은 생물이라는 점을 놓치지 않아야 해. 낙엽처럼 설명이 필요한 대상은 초기 분류 문제의 혼동용 카드로 넣기보다 2장의 분해 관찰에 사용하는 편이 좋아.

완료 제안: 지정한 단서를 관찰하고 핵심 분류를 마치면 생태계 구성 요소 기록 한 장을 얻어.

### 2장

P03에서 식물이 자라는 모습, 동물이 먹이를 먹은 흔적, 낙엽이 분해되는 흔적을 보고 생산자·소비자·분해자 역할을 연결해.

P04는 예측 → 한 역할 그룹 비활성화 → 시간 변화 관찰 → 예측과 비교 → 원래 상태 복원 순서로 진행해. 여러 조건을 동시에 바꾸기보다 한 번에 하나만 바꿔야 원인을 이해하기 쉬워.

완료 제안: 역할을 구분하고 실험 한 번의 관찰 결과와 이유를 기록해. 실험 결과는 검토한 교육용 상태 데이터로 표현하며 실제 생태계의 정밀 예측처럼 제시하지 않아.

### 3장

P05에서 생물 카드를 연결해 먹이그물을 만들어. 화살표 의미는 화면 전체에서 '먹히는 생물 → 먹는 생물'로 통일해. 선 연결은 드래그뿐 아니라 두 대상을 차례로 누르는 방식도 고려해.

P06에서 한 생물이 사라졌을 때 연결선과 남은 먹이 선택지가 즉시 바뀌어. 단순한 그물과 대체 먹이 경로가 있는 그물의 A/B 동시 비교, 되돌리기, 다른 생물 제거와 재실험이 핵심이야. '복잡하면 언제나 안전하다'고 일반화하지 않아.

완료 제안: 핵심 관계를 연결한 뒤, 선택한 변화가 영향을 주는 생물과 그 이유를 한 가지 설명해. 샘플의 모든 화살표를 그대로 복사하지 말고 생물 종과 관계를 먼저 검토해야 해.

### 4장

P07은 '인간 활동 → 환경 변화 → 생물 영향'의 인과 연결 활동이야. 단서가 뒷받침하는 연결을 선택하도록 하고 모든 인간 활동을 무조건 나쁜 것으로 다루지 않아.

P08에서는 같은 장소의 전후 모습을 슬라이더나 시간 단계로 비교해. 서로 다른 그림을 단순 나열하기보다 물 상태, 서식처, 생물의 변화가 같은 위치에서 보이게 해.

완료 제안: 원인과 결과 한 묶음을 연결하고 변화 전후의 근거를 찾으면 조사 기록을 얻어. 그림의 1일·7일·30일은 검토 전에는 실제 회복 기간으로 확정하지 않아.

### 5장

P09는 자유 배치보다 한정된 자원으로 대책을 조합하는 의사결정이 핵심이야. 오염원 줄이기, 하천 정화, 서식처 보호, 나무 심기의 역할 차이가 결과로 드러나야 해.

P10은 종합 생태계 설계와 최종 가동이야. 생물·비생물 요소 배치 → 양분 획득 역할 확인 → 먹이 관계 연결 → 관계 변화 시험 → 보전 전략 적용 → 생태계 가동으로 이어져. 약한 연결이나 필요한 조건을 확인하고 수정·재실행한 뒤 완료해. 마지막 화면을 '완료 버튼과 예쁜 배경'으로 축소하면 원래 설계의 핵심이 빠져.

선택한 대책에 따라 개선된 곳과 남은 문제를 보여줘. 어떤 조합을 골라도 같은 완벽한 엔딩이 나오면 전략 선택의 의미가 사라져. 성공 후 생명의 연결이 이어지는 장면, 단원 보상, 엔딩·인증서가 연결되는 흐름을 유지해.

완료 제안: 예산 안에서 행동을 선택하고 결과를 확인한 뒤 선택 이유를 정리하고, P10의 종합 설계를 실행·수정해. 이전 대화의 텍스트 설계와 샘플 P09는 6포인트이고 별도 시안 24번은 8포인트야. 후기 첨부 설계 문서 원문을 아직 받지 못했으므로 최종 예산과 비용표는 대화에서 통일해야 해.

## 재미와 몰입을 위한 MVP 제안

1. **조사가 다음 행동에 쓰이게 해.** 앞에서 찾은 단서가 실험 선택과 마지막 복원 결정의 근거가 되도록 연결해.
2. **장 완료가 지도에 보이게 해.** 조사 기록이 채워지고 해당 장소의 신호등이나 연결선이 바뀌어. 실제 복원은 마지막 전략 실행 결과와 연결해, 조사만으로 오염이 사라지는 표현은 피하자.
3. **정답 확인 전에 예상하게 해.** 실험 전 예측과 이후 관찰의 차이가 작은 발견이 되게 해.
4. **선택의 결과를 다르게 보여줘.** 복원 대책에 따라 물가·숲·서식처의 변화가 달라져야 재도전할 이유가 생겨.
5. **안내 캐릭터를 모아로 통일해.** 부엉이는 이전 대화에서 명시적으로 금지했어. 짧은 반응과 표정으로 함께 조사하는 느낌을 줘.

새 전투·상점·장비 강화·온라인 경쟁을 추가하기보다 이 흐름 안에서 발견과 선택의 재미를 먼저 완성하는 편이 맞아.

## 공통 UI 동작 제안

- 홈: 현재 진행을 저장하고 메인으로 이동. 메인에서는 홈 버튼이 현재 위치임을 표시해.
- 이전: 바로 전 활동이나 지도 등 실제 이동 경로로 돌아가. 첫 화면에서는 비활성 상태를 명확히 해.
- 소리: 배경음·효과음·음성의 전체 음소거를 토글하고 설정을 유지해. 음성 없이도 안내를 읽을 수 있어야 해.
- 설정: 관리자 전체 해금 한 번으로 5개 장과 모든 활동에 접근할 수 있어.
- 전체 해금은 완료 처리와 분리해. 조사 증거, 정답 기록, 최종 복원 결과를 자동으로 달성시키지 않아.
- 아이콘 위치는 지도, 활동, 결과 화면에서 동일하게 유지해. 새 터치 영역은 48×48px 이상을 기준으로 검토해.

|---|---|---|
| 메인 | 기존 2D 배경과 타이틀 | 현재 에셋 재사용 우선 |
| 자연 탐험 지도 | 2.5D 픽셀아트와 이동 캐릭터 | 2D 타일·스프라이트만으로 가능. 필요하면 3D 모델을 동일 각도로 렌더해 픽셀 스프라이트 제작에 활용 |
| 역할 실험 P04 | 2D 화면 속 생태 모형 | 3D로 제작한 모형의 상태별 렌더를 사용하면 입체감과 2D 화면 규칙을 함께 유지 |
| 시간 변화 P08 | 같은 시점의 2D 전후 비교 | 동일 장면의 상태별 렌더 또는 레이어 교체 활용 |
| 최종 설계와 가동 P10 | 요소 배치·관계 연결·실행이 가능한 2D 장면 | 물·빛·생물 레이어와 관계선 상태를 변화시켜 결과 표현. 전체 3D 월드는 MVP 필수 아님 |

이전 대화에서는 P01·P08·P10의 실시간 3D 안을 적용해 PRD/TRD로 정리했다고 안내했어. 이번 요청의 2D 원칙이 그보다 최신이므로 표현 방식은 바꾸고 해당 화면의 탐색·시간 변화·최종 설계 기능을 보존해. 자유 회전 가능한 실시간 3D 관찰 창은 현재 범위에 포함하지 않았어.

## PRD와 TRD로 넘어갈 때 정할 내용

- 후기 심화안의 보고서·최종 미션·엔딩·인증서를 P10 안에 묶는 세부 순서.
- 지도에서 움직이는 주인공과 다섯 목적지의 이름.
- 4학년, 전자칠판·태블릿 가로·웹앱 조건 안에서 목표 플레이 시간과 우선 검증 기기.
- 생물 목록·먹이 관계·실험 결과·복원 전략의 교육 내용.
- 복원 예산과 실제 선택 결과의 차이.

이 단계에서는 장별 흐름 검토와 자료 정리까지만 진행했어. PRD/TRD 본문 확정과 게임 코드는 대화 이후에 작성해.
