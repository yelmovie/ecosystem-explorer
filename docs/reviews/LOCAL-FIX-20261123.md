## 재실행

Node 기본 검사에는 외부 패키지 설치가 필요 없다.

```sh
npm run check
npm test
npm run build
PORT=4197 npm run preview
```

별도 터미널에서 기존 Playwright 설치와 Chrome 실행 경로를 지정한다.

```sh
STUDENT_PATH_ONLY=1 TEST_URL=http://127.0.0.1:4197 \
PLAYWRIGHT_MODULE=/path/to/playwright \
CHROME_PATH=/path/to/chrome \
node scripts/verify-experience.cjs
```

`STUDENT_PATH_ONLY=1`은 기존 검증 스크립트의 합성 저장 주입 검사에 들어가기 전에 종료한다. 위 결과는 이 모드로 확인했다. 산출물은 Git에서 제외되는 `artifacts/experience-check/`의 `student-path-result.json`, 완료 기록, 스크린샷, `certificate-export.png`, `certificate.pdf`다. 기본 모드 전체(뒤쪽의 별도 저장 주입·타이머·추가 화면 스윕)는 이번에 재실행하지 않았다.
