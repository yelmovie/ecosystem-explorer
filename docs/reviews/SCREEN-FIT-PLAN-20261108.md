# 한 화면 활동·자동재생 구현 기준

사용자 요청에 따라 기존 세로 스크롤 허용 방식을 교체한다. 활동 화면은 제목·한 줄 행동 안내·넓은 학습면·하단 재생 도구로 구성하고 장면과 필수 조작을 동시에 보여 준다. 1920×1080, 1366×768, 1280×800, 1024×600 및 작은 가로·세로 화면을 검사한다. 작은 화면은 논리 레이아웃을 균등 축소해 모든 조작을 유지한다.

같은 행동 지시를 헤더·장면·하단에서 반복하지 않는다. 주요 다음 행동은 테두리로 표시하되 정답 선택지는 후보 모두를 똑같이 표시한다. 도움말·이론·지난 기록은 필요할 때만 연다.

자동재생은 시작·일시정지와 0.5/1/2배 속도를 제공한다. P01 관찰 대상 열기, P04 시간 진행·복원, P06 두 제거 조건 비교, P08 두 대책 전후 관찰, P09 사용자가 고른 작전 실행, P10 사용자가 만든 설계 시험만 자동화한다. 분류·역할·먹이 연결·인과 추론·예상·설명·보전 대책은 자동으로 정답을 고르지 않는다. 답이 필요하면 재생을 멈추고 다음 조작을 표시한다. 화면 이탈·숨김·모달·수동 조작 시 타이머를 정리한다. 재생 상태는 진행 기록에 저장하지 않는다.

담당 파일: 공통 레이아웃은 stage-layout.css, 활동별 장면은 experiences.js, 제어·중복 정리는 app.js와 learning.js, 순수 재생 계획과 회귀 검사는 playback.js 및 tests/playback.test.mjs. 기존 저장·정답·증거 수집 규칙과 원화, 미커밋 변경은 보존한다. 새 의존성·외부 배포는 추가하지 않는다.

완료 기준: 문서·활동면 스크롤 0, 필수 조작 가림/이탈 0, 중복 행동 안내 제거, 재생이 답·완료를 임의로 만들지 않음, 속도/정지/이탈 회귀 검사와 전체 플레이·빌드 통과.
