# 14. 생명의 그물 지도 · 생물과 환경

검토·수정일: 2026-11-07. 대상: `/Volumes/T7 Shield/iscreammedia_sc34/14 environments`. 1~5는 완성본 참조이며 이번 변경 대상이 아니다. 운영시트의 단원 순서와 프로젝트 PRD의 4학년 생물과 환경 목표를 사용했다. 이번 작업에서 운영시트 원문이나 국가교육과정 고시를 재조회하지 않았으므로 성취기준 코드·교과서 판본 일치를 새로 인증하지 않는다.

## 판정
기존 자연 배경, 모아/도토, 2.5D 지도와 2D 활동 구조는 보존했다. 그림 부족보다 학습 증거 보존과 교사 시연/학생 저장 분리, 실제 조작 오류가 우선 문제였다. 수정 후 로컬 기능 검증 통과. 실물 태블릿 및 학교 수업 관찰은 미실시이며, 공식 납품 승인이나 학습효과 실험 결과가 아니다.

## 실제 적용한 개선 프롬프트

> 생명의 그물 지도 고유의 자연 배경·모아/도토·2.5D 지도와 2D 학습 활동을 보존하라. 10활동의 관찰→분류→역할 실험→먹이관계→환경변화→복원 설계 흐름과 제한된 자원/충격 후 수정 조건을 유지하라. 교사 전체해금은 학생 원본을 건드리지 않는 임시 시연으로 바꾸고, 모든 경로에 시연 표시와 학생 탐험 복귀를 제공하라. 기존 손상·새 버전 저장을 자동 덮어쓰지 말고 보호 상태를 안내하며, 초기화 전에 원본을 백업하되 백업 실패 시 초기화를 중단하라. 다른 탭의 변경도 감지해 덮어쓰지 마라. 완료 시 최초 증거를 독립 복사하여 재실험이 최종 보고서의 예상·관찰·작전을 바꾸지 못하게 하라. 실제 브라우저로 전 활동을 끝까지 플레이해 오류를 수정하고 1366×768, 1280×720, 1024×768, 768×1024, 390×844의 넘침·터치·포커스를 확인하라. 영상 실패 시 글 대체 및 음소거·동작 줄이기를 유지하라. 기존 삽화/CC0 음향이 충분하면 새 생성으로 용량과 자원을 쓰지 마라. 기존 변경 보존, 1~5 무수정, 커밋/배포/영구삭제 금지.

## 적용 파일
- `src/storage.js`: 상태 읽기/보호/동시창 감지, 초기화 백업과 복구.
- `src/engine.js`: evidence 독립 저장 및 엄격 복원. 기존 완료기록은 마지막 저장 상태에서 이관.
- `src/app.js`: 교사 시연 분리/복귀, 보호 메시지·초기화/복구 확인, 완료 스냅샷·보고서 연결, P08 슬라이더 오류 수정.
- `src/screens.css`: 시연 배너, 키보드 포커스, 좁은 화면 터치 목표 보완. 기존 파일의 미커밋 내용 유지.
- `tests/storage.test.mjs`: 새 6개 저장/증거 회귀 테스트.
- `scripts/verify-record-safety.cjs`: 실제 클릭으로 시연 격리·손상 저장 보호·백업·증거 유지 검증.
- `scripts/verify-experience.cjs`: 교사 unlock 대신 정상 선행기록으로 테스트 준비, 세로 태블릿/휴대폰 추가.
- `package.json`: 새 모듈 syntax 검사 포함. `.gitignore`: macOS `._*` 메타데이터만 제외.
- `dist`: 로컬 빌드 갱신. 원본 이미지·음향 추가 생성/삭제 없음. 신규 커밋·배포 없음.

## 학습 단계 중복 검토
P01 특징 관찰과 P02 새 사례 분류는 관찰-전이 관계다. P03 역할 조사와 P04 한 변수 제거 실험은 지식-검증 관계다. P05 관계 구성, P06 대체 먹이 비교, P10 충격 후 설계 수정은 같은 개념을 다른 판단에 사용하는 누적 탐구다. P07 원인 추론, P08 조건의 전후 비교, P09 예산 내 전략, P10 직접 설계는 동일 버튼 작업 반복이 아니다. 단, 정답 선택이 포함된 P01/P02/P03은 교실 관찰로 난이도 조절할 여지가 있다.

## 남은 제한
실물 iPad/학교 전자칠판, 학교망, 인쇄 PDF 결과, 스크린리더 전체 동선, 학생 대상 수업효과, 공식 성취기준·교과서 판본 대조, Momo 음성 생성/자연스러움 검증은 미실시. 자산의 외부 납품 권리 재검증도 별도다. 저장은 같은 주소·브라우저에만 유지되며, 보호 상태에서는 새로고침 전 임시 진행이 사라질 수 있다. 초기화 백업은 한 개이고 다음 초기화에 교체된다. 자동 실제 사용자 기록 초기화는 수행하지 않았다.
