# 14 생물과 환경: 최종 대사 통합

- 모아 환영 1, 활동 안내 10, 도토 첫 단계 힌트 10, 장 요약 5, 인증서 1의 총 27개 대사를 연결했다.
- 각 활동의 모아 안내 팝업과 도토 힌트 팝업에 원문·다시 듣기를 제공한다. 보고서 요약은 확보한 증거에만 연결한다.
- 단일 내레이션, 수동 재생·정지·다시 듣기, 음소거, 화면 이동·팝업 닫기·숨김 중단, 오류 시 글로 계속하기를 적용했다. 기존 환영 파일과 폰트는 보존했다.
- 지속 배경음은 기존 앱에 없으며, 내레이션 중 기존 procedural 효과음을 억제한다.

## 최종 빌드 검증

- `npm run check`, `npm test` 50개, `npm run build` 통과. 27개 출력 MP3와 출처 SHA 일치.
- Chrome에서 27개 실제 화면 버튼으로 재생 `playing`과 `ended` 확인, 재생 중 정지·음소거·화면 이동·팝업 닫기·단일 재생·숨김 이벤트 중단 통과.
- `verify-experience.cjs`: p01~p10 전체 학습, 수정·변화 대응 시험·엔딩·인증서 재로드, 터치 회귀 통과.
- `verify-playback.cjs`, `verify-record-safety.cjs` 통과.
- `verify-responsive.cjs`: 1280×800, 1920×1080, 915×412의 85개 상태 문제 0. 제목 경계 검사도 추가했다.
- 스크린샷에서 제목 위쪽 잘림을 발견해 모아 안내를 별도 팝업으로 옮겼으며, 최종 인증서 화면을 재확인했다.
- `graphify update .` 완료.

## 검증 한계

- 음성 ASR 27개 모두 공백·문장부호 정규화 후 원문 일치, 음량 −16.4~−16.0 LUFS. 사람의 실제 스피커 청취는 수행하지 않았다. ASR·재생 이벤트는 주관적 음색·발음의 보증이 아니다.
- 브라우저 자동화는 헤드리스 Chrome에서 수행했다. 숨김은 visibilitychange 이벤트로 검증했다.
