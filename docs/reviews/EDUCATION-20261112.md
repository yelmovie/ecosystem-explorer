# 생명의 그물 지도 교육 흐름 최종 검토

2026-11-12 KST. 초등 3~4학년군 과학 「생물과 환경」의 관찰·분류 → 역할 → 먹이 관계 → 인간의 영향 → 보전 대책 → 설계·시험·생활 실천 순서로 10페이지를 대조했다. 기존 물가 탐험의 시각 체계와 저장 형식을 유지하며 교육 내용과 다음 행동 안내를 보완했다.

검토 판정은 **조건부 납품 가능**이다. 운영 배포와 자동 검증을 완료했고 교사 수업 검수·실제 학교 기기·제공 에셋 권리 확인이 남아 있다.

## 교육과정과 과학 내용

교육부 고시 제2022-33호 원문 ZIP의 별책 9 HWP에서 최종 고시 문장을 추출했다. 앱의 [4과14-01], [4과14-02], [4과14-03] 세 문장이 공백 정규화 후 모두 일치했다. ‘양분을 얻는 방법에 따라 생물 요소 분류하기’는 공식 탐구 활동이므로 P03의 확장 활동 표시를 바로잡았다. P04 역할 제거 실험은 이해를 돕는 확장 모형으로 표시한다. 원문·해시·문장 대조 결과는 기계 판독용 증거 파일에 기록했다. [교육부 고시 원문](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&search=)

먹이 화살표는 먹히는 생물에서 먹는 생물로 향한다. 대체 먹이 경로가 남을 때 먹이 이용의 가능성을 설명하고 물·기후·서식처 조건도 함께 고려하도록 했다. 죽은 나무에서 양분을 얻는 버섯은 분해자의 한 사례로 설명하며 세균 중에도 분해자 역할을 하는 생물이 있음을 표시했다. [NParks 먹이 관계 설명](https://biodiversitysg.nparks.gov.sg/our-ecosystems/food-webs/food-chains-and-food-webs-basics/), [미국 국립공원청 생태계 기능](https://www.nps.gov/subjects/biodiversity/services-provided-by-biodiversity.htm)

모든 페이지의 ‘개념·안내’에는 핵심 개념, 범위를 분명히 하는 설명, 생각 나누기 질문과 기존 음성 조작 안내가 들어간다. 개념·힌트·현재 행동·완료 피드백의 핵심어를 강조했다. 틀린 선택을 고치고 결과를 다시 비교하는 경로를 유지했다. 설계 3미션은 생물 배치·먹이 화살표·환경 조건·쓰레기 수거 계획을 다시 적용하는 활동으로 검토했다.

## 흥미·이해·성취를 연결한 변경

- ‘지금’ 안내 문장과 테두리로 표시한 버튼이 같은 상태 판정을 사용한다. P08 마지막 장면에서 새로 생기는 답변 버튼도 바로 표시한다.
- ‘부재 시험·가동’을 ‘메뚜기 없이 시험·생태계 시험’으로 바꾸고 서식처를 생물이 사는 곳으로 풀었다. 단계별 힌트와 자동 진행 뒤 직접 조작 경로를 유지했다.
- 완료 피드백에 이번 활동에서 이해한 개념을 담았다. 엔딩의 실천 선택에는 이유를 표시하고 친구·가족에게 고른 까닭을 이야기하도록 안내한다.
- 실천 선택은 생활 속에서 해 볼 계획으로 저장한다. 실제 실천 여부와 학습 효과는 수업에서 관찰해야 한다.

## 새 그림과 저장

생성 그림 2장을 외장 SSD에서 WebP로 최적화했다. `forest-floor-lab-v3.webp` 255,530바이트는 P04·P10에, `decomposer-log-v3.webp` 191,894바이트는 P03·P04 안내에 적용했다. 기존 생물 삽화·글자·조작은 독립 요소로 유지했다. 균사를 크게 나타낸 설명 그림이라는 캡션을 표시했다.

## 점수와 남은 확인

고정 감점 규칙의 점수는 **88/100, 8.8/10**이다. 핵심 개념·설계 흐름·반응형 기능은 보완했고 교사 수업 검수, 실제 초등학생 40분 사용, 실제 학교 태블릿·Safari·125% 확대, 실제 프린터, 제공 에셋 권리 확인 등의 감점 조건은 남아 있다. 세부 산식과 10개 항목은 [점수표](SCORE-20261111.md)에 기록한다.

이 게임은 과학적 관계와 모형의 한계를 설명하고 실패 뒤 수정하는 활동을 제공한다. 실제 학습 성취·흥미·실천 여부는 교사의 관찰과 학생 설명으로 확인해야 한다. 기존 완료 목록의 로컬 직접 수정 가능성, 오프라인 새로고침 미지원, 큰 소스 파일 등 확인된 제한도 점수표에 반영했다.

실행 로그·캡처·원문·그림 원본은 외장 SSD의 `artifacts/education-20261112/`에 있다. 기계 판독용 결과는 [최종 교육 검증 증거](EDUCATION-EVIDENCE-20261112.json)에 기록했다.
