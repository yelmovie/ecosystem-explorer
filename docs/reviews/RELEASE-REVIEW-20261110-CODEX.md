## 적용한 변경

1. curriculum.js에 고시본과 대조한 원문·출처·검수 메타를 기록. learning.js의 각 활동에 해당 기준을 연결하고 교사용 안내에 표시.
2. 폰 가로의 상단 홈·뒤로·음소거·설정4버튼만 무대 축척을 보정해 실제44px을 확보. 모든 버튼을 일괄 확대하면 도식이 잘려 그 시도는 되돌렸다.
3. 반응형 검사기의 터치 기준을44×무대축척이 아닌 실제44 CSS px로 고쳐 작은 목표를 숨기지 않도록 했다.
4. verify-experience의 모바일 구간을 별도 브라우저로 격리. 데스크톱 미디어 실패 fixture 뒤에 이어 실행할 때 생긴 검사기 멈춤을 해소했고 앱 학습 로직은 바꾸지 않았다.
5. 생성 dist에만 macOS 메타파일 정리와 배포 ignore를 적용.
