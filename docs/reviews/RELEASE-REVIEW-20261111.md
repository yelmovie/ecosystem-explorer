## 실행 증거

- 구문 검사·단위 58개·프로덕션 빌드가 통과했다. 별도 lint·TypeScript 명령은 프로젝트에 없어 NOT APPLICABLE이다.
- 활동 반응형 검사는 1920×1080, 1280×800, 1024×768, 1024×600, 915×412, 768×1024, 390×844와 추가 360px 힌트에서 총 197상태를 확인했다. 검출 이슈와 런타임 오류는 0건이다.
- 추가 미션·홈·지도·설정은 49상태, 안내·힌트·개념 창은 120개를 확인했다. 오답·되돌리기·닫기·재진입·저장 충돌까지 검사했다.
- 그림과 텍스트가 만나는 부분은 자동 검사에 더해 P01~P10, 홈·지도·미션·인증서·태블릿과 작은 화면 캡처를 직접 열어 확인했다. 스크롤 배치에서는 각 버튼을 스크롤해 중앙 좌표의 실제 클릭 대상을 확인했다.
- 운영 전체 흐름 15검사·50배치, 자동 진행 12검사, 음성 27개, 저장 회귀, 영상 10편, 지도 복구 5구역이 통과했다. 마지막 CSS 배포 후 파일 128개 재대조와 엔딩 7크기·추가 화면 49상태를 재검사했다. 마지막 CSS 변경은 엔딩 그림 배치에 한정되며 전체 흐름·영상·음성 검사 당시의 JavaScript와 배포 JavaScript가 일치한다.

## 성능과 인쇄

공개 주소의 load는 2.08 / 2.42 / 2.17초, 평균 **2.22초**였다. 평균 LCP는 2.25초, 첫 화면 평균 전송은 1.83MiB, CLS는 0.0010였다. 초기 표시와 영상 지연 로딩을 확인했다.

Chrome의 새 컨텍스트 3회, 1280×800, 캐시 비활성, 10Mbps·지연 40ms 조건을 사용했다. 데스크톱 Chrome 지도 프레임 측정은 5초 동안 301회, 간격 평균 16.62ms, p95 16.8ms, 50ms 초과 0회였다. CPU 제한 없이 헤드리스 Chrome에서 측정했고 실제 학교 기기 성능은 별도 조건이다.

인증서는 A4 PDF 1페이지로 생성됐고, 인쇄용 화면에서 음성 버튼 제거·한글·잘림을 확인했다. 실제 프린터와 iOS Safari 인쇄·공유는 NOT TESTED이다.

## 검증 중 수정한 검사 조건

운영 CDN은 영상 Range 요청에 전체 파일 200 응답을 반환했다. HTTP는 Range 무시를 허용한다. 검사기는 200과 206 각각의 응답 바이트를 원본과 대조하도록 보완했다. 추가 브라우저 검사에서 실제 장면 이동이 0초로 돌아가는 문제가 재현돼 앱의 짧은 영상 로딩을 Blob 방식으로 수정했다. 이후 5초·10초 위치뿐 아니라 seek 완료와 디코딩 준비 상태까지 확인했다. [RFC 9110 §14.2](https://www.rfc-editor.org/rfc/rfc9110.html#section-14.2)

첫 운영 스모크의 홈 버튼 선택자를 실제 `data-action="go"`에 맞춰 고쳤다. 빌드 교체와 겹친 음성 검사 한 번은 타임아웃이 나서 빌드를 고정한 뒤 27개를 다시 실행했다. 운영 영상의 원본 바이트 검사에서 네트워크 읽기가 30초를 넘긴 1회는 실패로 남겼고, 파일 검사 제한을 90초로 늘려 전체 정상 경로를 다시 통과했다. 자동 진행 결과를 복사하는 경로도 실제 stage-player 폴더에 맞춰 정정했다. 수정 전 실패 로그와 최종 결과는 외장 증거 폴더에 남겼다.
