# 스테이지 반응형·학습 시각화 개선 — 2026-11-08

10개 활동의 글자·아이콘 겹침을 수정하고 기존 자연 삽화와 CSS 장면을 함께 다듬었다. 파일을 나눈 병렬 구현 후 실제 Chrome에서 통합 검증했다. 기존 미커밋 작업을 보존했으며 저장·정답·해금 규칙과 원화는 유지했다.

## 발견한 원인과 공통 수정

- 관찰 대상의 이름이 버튼 바깥에 절대배치되어 다른 라벨과 겹치거나 장면 밖으로 잘렸다. 이름과 그림을 한 버튼 안에서 배치하고 햇빛 버튼의 상단 여유를 확보했다.
- 고정 크기 먹이그물 노드가 좁은 비교 칸에 몰렸다. 판 자체의 너비에 맞춰 크기를 조절하고 비교판을 넓은 화면에서는 두 열, 좁은 화면에서는 한 열로 배치했다.
- 선택 표시·삽화·긴 문장이 한 버튼의 익명 flex 항목으로 섞였다. 본문에 `choice-label`을 추가해 표시와 본문의 공간을 나누고 한글 줄바꿈과 최소 너비를 보완했다.
- 최종 설계 팔레트의 체크 표시가 작은 카드의 그림에 겹쳤다. 체크 표시 전용 상단 공간을 확보했다.
- 작은 화면에서 힌트가 관찰 대상을 덮었다. 안내 패널 안의 별도 행으로 펼쳐지도록 바꿨다. 교사용 다음 단계 버튼도 문서 흐름에 배치했다.
- 활동 전환 후 부드러운 스크롤이 남아 드래그 도중 좌표가 바뀌었다. 전환 시 화면 위치를 즉시 초기화했다. 추적에서 드래그 전후 scrollY가 3→82로 바뀌던 현상을 확인했고 수정 후 배포용 빌드의 전체 플레이가 통과했다.

| P08 시간 비교 | 전후 캡션을 그림 밖으로 이동, 원본 비율 유지, 슬라이더·관찰 안내·회고를 반응형으로 배치 |
| P09 복원 전략 | 작은 화면에서도 대책 삽화 제공, 실행 여부와 대책별 역할 표시, 지난 작전 비교를 문서 흐름에 배치 |
| P10 최종 설계 | 세 탭·팔레트·환경 토큰·진단·시험 버튼의 너비와 줄바꿈 정리, 엔딩·인증서까지 검증 |

## 수정 파일

- `src/app.js`: 선택지 본문, 힌트 구조, 먹이 관계 범례, 활동 식별자, 전환 스크롤.
- `src/screens.css`: 공통 반응형·터치·한글·힌트·분류/역할·최종 팔레트·복원 카드 보완.
- `src/experience.css`, `src/experiences.js`: 실험·비교·인과·시간·복원·최종 설계 화면의 구조와 설명.
- `src/learning-art.css`, `src/visuals.js`: 장면·노드·삽화·복원 대책의 시각 표현.
- `index.html`: 안전 영역을 위한 viewport-fit 설정.
- `scripts/verify-responsive.cjs`: 실제 텍스트 범위, 아이콘 겹침, 장면 잘림, 버튼 가림 등을 검사하는 브라우저 하네스.
- `scripts/verify-experience.cjs`: 브라우저 캐시 경로와 충돌 보고 비활성화 보완. 기존 기능 검증 유지.
