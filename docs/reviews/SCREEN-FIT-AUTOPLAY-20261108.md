# 한 화면 활동·자동재생 적용 — 2026-11-08

사용자 후속 요청에 따라 **기존의 활동 페이지 세로 스크롤 허용 방식을 교체**했다. 10개 스테이지의 실험 장면, 선택지, 조작·완료 버튼을 한 화면에 배치했다. 이전 `RESPONSIVE-DESIGN-20261108.md`의 스크롤 허용 설명은 이 변경으로 대체된다.

## 화면 구성

- 제목과 공용 이동·설정 도구를 같은 상단 행에 모았다.
- 다음 행동 안내는 한 줄로 모으고, 현재 선택할 수 있는 대상에 테두리를 표시했다. 정답이 있는 선택지는 후보 모두를 같은 방식으로 표시해 정답을 미리 알려 주지 않는다.
- 장면과 조작을 활동별 그리드에 배치하고 하단 재생 도구·완료 버튼의 행을 따로 확보했다.
- 반복되는 행동 안내, 자동 기록 안내, 그림 범례, 확인 횟수와 중복 삽화를 정리했다. 이론·힌트·먹이 수첩·완료 증거는 필요할 때만 열도록 했다.
- 역할칸에 놓인 카드는 이미 읽은 설명을 반복하지 않고 그림·이름으로 압축했다. 잘못 배치한 카드 여러 장도 같은 화면에서 다시 선택할 수 있다.
- P10의 요소·먹이 길·보전 대책, 시험 실패 진단, 엔딩·인증서까지 같은 화면 틀을 사용한다.

화면에 맞춘 논리 무대 크기를 먼저 정하고 작은 화면에서는 전체를 균등 축소한다. 기본 가로 무대의 최소 기준은 1000×562, 세로는 640×960이며 실제 화면 비율에 따라 논리 영역을 늘려 공간을 채운다. 1024×600 이상의 가로 화면은 원래 크기로 배치한다. 작은 화면의 터치 영역도 함께 축소되므로 실제 기기 가독성과 터치 정밀도 확인은 남아 있다.

## 자동재생 범위

| 스테이지 | 자동으로 진행하는 과정 | 학습자가 직접 하는 것 |
|---|---|---|
| P01 | 다음 관찰 대상 열기 | 특징 설명 선택 |
| P02·P03 | 자동재생을 제공하지 않음 | 생물 분류·역할 판단 |
| P04 | 예상 선택 후 시간 진행·복원 | 예상과 관찰 기록 선택 |
| P05 | 자동재생을 제공하지 않음 | 먹이 관계 연결 |
| P06 | 메뚜기·개구리 제거 및 복원 비교 | 두 모형 반응의 까닭 선택 |
| P07 | 자동재생을 제공하지 않음 | 원인·환경 변화·생물 영향 추론 |
| P08 | 두 대책의 전후 관찰·슬라이더 진행 | 비교해서 알게 된 사실 선택 |
| P09 | 학습자가 고른 작전 실행 | 대책 조합과 선택 이유 |
| P10 | 학습자가 만든 설계의 가동·메뚜기 부재 시험 | 설계·수정·복원 완료 확인 |

0.5배·1배·2배, 일시정지·이어재생을 제공한다. 재생은 정답 선택·먹이 연결·보전 대책·완료 처리를 대신하지 않는다. 답이나 수정이 필요하면 멈춘다. 수동 조작, 도움말·접힌 설명 열기, 화면 숨김·이탈 시 예약된 동작을 정리한다. 일시정지 후 재개는 현재 관찰 조건에서 이어지며 재생 상태는 학생 진행 기록에 저장하지 않는다.

## 검증

- `npm run check`, `npm test` **32개**, `npm run build` 통과. 순수 재생 계획 안전성 테스트 8개를 구현 전에 작성했다.
- **배포용 dist에서 7가지 크기 × 활동·상태 및 힌트 총 197개 조합: 문제 0건, 브라우저 예외 0건.**
- 크기: 1920×1080, 1366×768, 1280×800, 1024×600, 740×360, 800×270, 360×740.
- 문서 세로·가로 스크롤, 활동 영역 내부 스크롤, 화면 밖 조작, 글자·아이콘 겹침, 잘린 글자·노드, 실제 버튼 가림, 깨진 이미지를 검사했다. 소형 화면의 터치 크기는 균등 축소 배율을 반영해 검사했다.
- 초기 화면뿐 아니라 관찰 수첩, 올바른·잘못된 분류/역할 배치, 실험 결과·복원, 연결 완료, 제거 비교, 시간 비교 질문, 복원 결과, 최종 설계 세 탭·실패 진단·엔딩·인증서를 포함했다.
- `verify-playback.cjs`: **12개 브라우저 검증 묶음 통과.** 자동 정답·자동 완료 없음, 속도 선택, 일시정지·이어재생, 도움말/설명 열 때 정지, 이탈 후 예약 동작 취소를 확인했다.
- `verify-experience.cjs`: **전체 플레이 15개 묶음과 50개 추가 레이아웃 통과.** 오답·드래그·터치·자동 기록·저장 후 이어하기·최종 실패→수정→성공·영상·움직임 줄이기 확인. 브라우저 예외·HTTP 자산 오류 0건.
- `verify-record-safety.cjs`: 교사 시연의 학생 기록 격리, 복귀·잠긴 경로, 손상 기록 보존, 초기화 백업, 증거 스냅샷 재실험·새로고침 보존 통과.
- 1024×600의 실제 화면과 작은 세로 화면을 직접 열어 확인했다. `git diff --check` 통과, Graphify AST 갱신 완료.

검사 자료는 외장 SSD의 `artifacts/stage-player/`와 `artifacts/responsive-check/stage-fit-final/`에 저장했다. 새 브라우저 검증은 별도 QA 프로필을 사용해 사용자의 실제 진행 기록을 초기화하지 않았다. 기존 미커밋 변경을 보존했고 원화·저장 키·정답 판정·증거 규칙은 유지했다. 신규 의존성·커밋·외부 배포는 추가하지 않았다.

실물 iPad/Safari·학교 태블릿·전자칠판과 학생 사용성은 미실측이다. 로컬 배포용 미리보기: http://127.0.0.1:4195/
