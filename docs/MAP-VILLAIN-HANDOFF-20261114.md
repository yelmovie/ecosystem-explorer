# 14 생명의 그물 지도 · 지도 악당 연계 계획

2026-11-14 · **초기 시안 기록.** 아래는 구현 전에 정리한 계획이다. 현재 구현은 [지도 연출](../src/map-encounters.js)과 [스테이지별 대사](../src/map-encounter-theme.js)를 참고한다.

운영 대응: [콘텐츠](https://ecosystem-explorer.yelsam.workers.dev/) · [GitHub](https://github.com/yelmovie/ecosystem-explorer). 작업을 다시 시작할 때 공식 운영 시트와 활성 지도 버전을 재확인한다.

## 외형과 등장

**끈 끊는 집게 봇 / 녹색 매듭, 나무 집게와 주황 끈의 벌어진 단면.** 스테이지 완료 기록 후 지도에 돌아올 때 해당 장소 옆에 등장한다. 기존 주인공·동료·건물의 스타일을 유지하고, 악당과 소품의 접점이 글 없이도 읽히게 그린다. 아래 소품 동작은 지도 위 짧은 장난 컷이다. 활동 화면이나 기존 학습 데이터에는 손대지 않는다.

모아·도토 지도 원본을 각자 기준으로 사용. 먹이 연결 장식은 학습 입력이나 실제 생물 타격으로 처리하지 않는다.

## 스테이지마다 바뀌는 소품·자세·대사

장소명은 기획상의 연결 기준이다. 활성 버전의 스테이지 ID와 이름을 대조한 뒤 키를 정한다. 선택 구역은 실제 별도 완료 이벤트가 있을 때만 추가한다.

| 장소 | 악당 스프라이트 동작 | 첫 등장 또는 접근 대사 예시 |
|---|---|---|
| 관찰의 물가 | 관찰 표지를 집게로 집어 숨기기 | “이 표시는 내가 먼저 찾았지!” |
| 양분의 정원 | 역할 그림 표찰을 빼고 끈 흔들기 | “이 그림은 빼 두자!” |
| 연결의 초원 | 잎과 애벌레 표지 사이 끈 벌리기 | “이 줄, 끊어 버렸지!” |
| 시간의 습지 | 변화 전후 표찰의 순서를 바꾸기 | “뒤에 있던 걸 앞으로!” |
| 복원의 연구소 | 복원 표지 앞에 매듭 묶기 | “이 매듭은 못 풀걸!” |

상황 대사 예시:

- 접근: “이 줄은 내가 끊었어!” / “매듭 하나 더 묶을까?”
- 1·2타: “앗, 매듭 하나 풀렸네!” / “집게가 자꾸 벌어져!”
- 퇴장: “실뭉치가 된 김에 굴러가야지!” / “끊은 줄은 두고 간다!”

스테이지 고유 문장을 우선하고, 상황 대사는 연속 반복 없이 고른다. 주인공·보조 캐릭터의 주민 대화와 겹칠 때는 악당 말풍선을 생략한다.

## 세 번의 타격과 접촉 피격

| 사건 | 이 프로젝트의 표현 |
|---|---|
| 1타 · 짧은 명중 | 초록 매듭이 한 번 풀림 |
| 2타 · 더 큰 반동 | 끈 끝 두 개가 튕겨 나감 |
| 3타 · 마무리와 퇴장 | 악당이 실뭉치처럼 말려 굴러가고 선 모티프만 짧게 이어짐 |
| 주인공 접촉 | 모아는 팔을 벌려 중심을 되찾음 |
| 보조 캐릭터 접촉 | 도토는 꼬리를 세우고 낮게 움찔했다 도로 펴짐 |
| 악당의 접촉 공격 동작 | 집게를 크게 벌렸다 한 번 ‘딱’. 닿는 쪽에 짧은 끈 끝 한 가닥이 튐. |
| 타격·퇴장 효과음의 차이 | 딱 → 타닥 → 데굴 |
| 접촉 효과음 모티프 | ‘툭, 타닥’ |

세 타격은 같은 공격 입력이다. 가까이 있는 상태에서 한 입력이 한 타로 계산된다. 접촉 피격은 닿은 쪽만 재생하고 공격 카운트와 학습 진행에는 영향을 주지 않는 것을 권장한다. 소리를 꺼도 표정·자세·게이지로 읽혀야 한다.

## 방향과 시선

집게와 시선은 상대 쪽으로 돌지만, 잎·애벌레의 관계 표시와 끊어진 두 끝은 지도에서 뒤집지 않는다.

## 제작하고 적용할 순서

1. 기존 진입점 확인: [src/data.js](../src/data.js) · [src/map-screen.js](../src/map-screen.js) · [src/map-path.js](../src/map-path.js). 활성 지도와 완료 상태, 실제 주인공/보조 지도 원본·이름, 기존 악당/스프라이트·대사·저장부터 확인한다.
2. 기본 악당 한 장, 위 표의 장소별 소품 동작 스트립, 공통 이동/접촉 전조/피격/퇴장 프레임을 제작한다. 주인공·보조 피격은 각각 4~6프레임. 소품이나 배경을 몸통 시트에 같이 구워 넣기 전에 지도 크기에서 알아볼 수 있는지 확인한다.
3. 별도 승인된 구현 단계에서 완료된 장소 좌표에 악당을 붙이고, 기존 HUD 근처에서 공격·타격·피격·퇴장만 연결한다. 기존 이동/화면 전환/복구 상태와 학습 완료/다음 장소 해금은 보존한다.
4. 완료 전/후, 정확한 3타, 두 아군의 개별 접촉, 퇴장 및 재진입, 빠른 연타, 무음·모션 감소·태블릿을 확인한다. 가장 작은 정상 지도 표시 크기에서 소품과 방해 동작이 구분되는지 본다.

이 계획을 작성할 당시에는 정적 이미지 합성과 시안 검토까지 마쳤다. 06 물의 상태 변화는 참고 사례로만 사용했다.
