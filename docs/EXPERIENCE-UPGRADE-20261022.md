# 개념 영상·태블릿 UX 개선 기록

2026-10-22. 기존 5장·10개 활동과 생태 판정 모형을 유지하면서 실제 조작, 학습 후 개념 정리, 화면 가독성을 개선했어.

## 적용

| 활동 | 조작·학습 흐름 |
|---|---|
| P01 관찰 | 배경 속 네 흔적 조사 → 관찰 특징 확인. 관찰 제목·아이콘을 한 줄로 모아 답변 영역을 확보했어. |
| P02 분류 | 여섯 카드를 생물·비생물 상자로 끌어 놓기. 카드 선택 → 상자 누르기도 가능해. 잘못 둔 카드도 다시 옮길 수 있어. |
| P03 역할 | 관찰한 양분 획득 방법을 생산자·소비자·분해자에 끌어 연결해. |
| P04 실험 | 예상 → 시간 진행 → 역할 복원 → 관찰 기록. 현재 단계의 조작만 보여주고, 분해자 제거 시 낙엽이 쌓이는 장면을 추가했어. |
| P05 연결 | 생물에서 생물로 직접 선을 끌어. 두 번 누르기도 유지해. 연결된 선에는 양분 이동을 나타내는 빛이 흘러. |
| P06 비교 | 메뚜기·개구리를 각각 제거해야 해. 같은 변화에서 A와 B에 남는 경로를 관찰한 다음, 별도 화면에서 차이의 원인을 설명해. |
| P07 원인 추적 | 여섯 카드 중 단서와 맞는 것을 골라 사람의 행동 → 환경 변화 → 생물 영향 칸에 놓아. 물가와 숲 두 사건을 조사해. |
| P08 시간 비교 | 사진 위를 손가락으로 쓸거나 슬라이더를 움직여. 두 대책에서 전후 네 장면을 확인한 다음 발견을 설명해. |
| P09 전략 | 6포인트 계획 → 실제 장면·상태 변화 → 이유 설명. 계획을 바꾸고 최근 세 작전 결과를 비교할 수 있어. |
| P10 설계 | 요소 배치·먹이 연결·보전 대책의 세 탭. 요소 끌어 배치, 가동, 메뚜기 부재 시험, 실패 후 수정까지 실제 판정해. |

종이 활동과 다른 점은 선택에 따라 화면과 연결 경로가 즉시 바뀌고, 같은 조건의 제거 실험과 서로 다른 복원 작전을 반복 비교하며, 마지막 설계가 변화 상황에서도 작동하는지 시험할 수 있다는 거야.

## 개념 영상

- P01–P10에 각각 다른 12초 MP4를 제작해 완료 직후 연결했어. 960×540, 24fps, H.264/AAC, faststart. 10편 합계 약 0.96 MiB야.
- 한 영상은 4초씩 세 장면이야. 한 번에 한 핵심 문장만 표시해. 한국어를 이미지에 직접 렌더링해 폰트나 자막 로딩에 의존하지 않아.
- 한국어 VTT, 포스터 JPG, 읽을 수 있는 개념 글도 함께 제공해. 다시 보기, 즉시 다음 활동으로 이동, 로딩 실패 시 개념 글 읽기가 가능해.
- 영상은 활동 완료의 추가 통과 조건이 아니야. 완료를 먼저 저장하고 사용자가 다음 활동으로 이동할 수 있어.
- 동작 줄이기 설정 또는 OS의 동작 줄이기 선호에서는 자동 재생을 꺼. 음소거도 영상에 적용돼.
- 재생 중 닫기·빠른 건너뛰기·화면 전환 시 영상과 소리가 정리돼.
- 소스: `src/learning.js`, `scripts/make-concepts.py`. 결과: `assets/concepts/`. 원본 배경과 캐릭터는 수정하지 않았어.

영상 설계에는 `ai-video-prompt`의 컷 길이·카메라·종료 구도 원칙을 적용했어. 인물이 등장하지 않는 도형 모션 영상이라 인물 캐릭터 시트는 필요하지 않아. 카메라는 고정·정면·도해 전체 프레임이고, 각 컷은 관찰 대상이 들어온 뒤 해당 조건의 결과를 유지하는 구도로 끝나. 손떨림이나 무리한 줌은 넣지 않았어.

| 영상 | 장면 1 · 4초 | 장면 2 · 4초 | 장면 3 · 4초 |
|---|---|---|---|
| P01 | 흐르는 물 | 자라는 풀·버섯 | 생물의 특징 |
| P02 | 생물 | 생활 환경 | 함께 이루는 생태계 |
| P03 | 양분을 만드는 역할 | 먹어서 얻는 역할 | 분해하며 얻는 역할 |
| P04 | 한 역할만 바꾸기 | 분해자 제거와 낙엽 | 복원 비교 |
| P05 | 식물 → 메뚜기 | 메뚜기 → 개구리 | 화살표와 양분 이동 |
| P06 | 기존 먹이 길 | 메뚜기 제거 | 다른 경로와 다른 환경 조건 |
| P07 | 오염을 일으키는 행동 | 물의 오염 | 생물에 생긴 영향 |
| P08 | 대책 없는 물가 | 함께 돌본 물가 | 전후 비교 |
| P09 | 한정된 자원 | 원인·서식처 함께 돌보기 | 작전 수정과 비교 |
| P10 | 요소·먹이 관계 | 변화 시험 | 시험 결과에 따른 수정 |

## 화면과 동물 친구

- 본문·주요 버튼은 20px 이상을 기본으로, 보조 문자는 16px 이상으로 정리했어. 전자칠판에서는 화면 폭에 따라 더 커져.
- 큰 왼쪽 설명 패널을 없애고 상단 현재 행동 안내와 하단 진행 버튼을 공통으로 배치했어. 긴 수첩·이전 실험 기록은 필요할 때 펼쳐.
- 팝업은 뷰포트 중앙에 놓이고 화면 안에서만 스크롤해. 영상 팝업도 같은 기준이야.
- 사람 탐험가가 지도에서 이동하고, 초록 스카프를 두른 다람쥐 도토가 조금 뒤에서 따라와. 기존 수달 모아는 연구원 안내자로 유지했어.
- 각 활동에서 도토를 누르면 힌트를 한 단계씩, 최대 세 단계까지 열 수 있어. 처음에는 조작, 다음에는 생각할 기준, 마지막에는 구체적인 단서를 알려 줘.
- `pointercancel` 처리로 끌기를 취소하면 떠 있는 카드와 선이 정리돼. 드래그 뒤 발생하는 클릭을 막아 같은 행동이 두 번 처리되지 않아.

## 검증

- `npm run check`, `npm test` 14개, `npm run build` 통과.
- 새 기록에서 관리자 해금 없이 10개 활동을 순서대로 완료했어. 오답 수정, 두 제거 실험, 네 시간 장면, 두 복원 작전 비교, 최종 설계의 실패·수정·성공, 인증서와 새로고침 저장을 확인했어.
- 모든 영상의 12초 메타데이터·실제 재생과 MP4 부분 요청(206)을 확인했어. 영상 로딩 실패, 빠른 건너뛰기, 소리 끄기, 동작 줄이기도 확인했어.
- Chrome의 터치 이벤트로 카드 끌기와 취소를 시험했어. 취소 후 떠 있는 요소는 0개이고 분류 기록은 바뀌지 않았어. 터치로 두 번 눌러 옮기는 방식도 통과했어.
- 1280×800, 1024×768, 906×755, 1920×1080, 1440×900, 873×580, 375×812에서 초기 84개 화면과 완료 상태 84개 화면을 점검했어. 가로 넘침과 44px 미만 버튼은 없었어.
- 설정·영상 팝업 14개는 모두 화면 안에 있었고 중앙 오차는 0px였어. 최종 설계 세 탭도 별도로 확인했어.
- 태블릿·전자칠판 기본 화면은 대부분 한 화면에 들어와. 작은 태블릿의 일부 실험·연결·대책 화면에는 짧은 세로 이동이 남아. 높이가 580px인 인앱 브라우저와 휴대폰 세로는 글자·터치 크기를 유지하며 자연스럽게 세로 스크롤해.
- 브라우저 예외와 HTTP 에셋 오류는 0개였어. 브라우저 검사 결과와 스크린샷은 `artifacts/experience-check/`에 보관했어.

실제 학교 태블릿·펜·전자칠판의 물리 터치 감도와 교실 뒤쪽 가독성은 기기에서 추가로 확인해야 해. 영상은 자막·도형과 짧은 시작음으로 구성돼 있고 나레이션은 없어. 외부 배포는 하지 않았어.
